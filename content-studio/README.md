# Zaya’s Ananda Center — өдөр тутмын пост

Сэдэв → Mac дээрх хичээлийн эхийг нягтлах → энгийн монгол тайлбар → нэг тогтмол загварын PNG постер.

Энэ хавтас нь бие даасан контентын хэрэгсэл. Одоо байгаа вэбсайтын кодыг өөрчлөхгүй. Facebook-д нийтлэхгүй. Фонт, байрлал нь хэрэглэгчээр хараахан батлагдаагүй студийн санал.

## Загвар

1080 × 1350. Дээд хэсэгт бүтэн нэртэй албан PNG лого. Lora Medium гарчиг, Manrope тайлбар. Өдөр бүр зөвхөн зураг ба үгээ солино. Багтахгүй эхийг товчилно. Фонтын хэмжээг автоматаар бууруулахгүй.

`brand/logo.png` нь эх албан WebP логог өөрчлөлтгүй PNG болгосон хувилбар. Цагаан дэвсгэртэй; тунгалаг гэж зарлахгүй. Нэрийг дахин шивж орлуулаагүй. Фонтууд SIL Open Font License-ийн хуулбартай. Засварлах SVG-д эдгээр фонт хэрэгтэй; PNG болон outlined SVG нь фонт суулгах шаардлагагүй.

## Ажиллуулах

Python 3.9+:

```sh
cd content-studio
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/render_post.py --draft examples/nature.json --image examples/pine.png --out outputs/nature-v1
```

Гаргалт: `poster.png`, `poster-editable.svg`, `poster-outlined.svg`, `caption.txt`, `draft.json`, `copy.txt`, `verification.json`. Байгаа хавтсыг дарж бичихгүй. Шинэ хувилбарын нэр хэрэглэнэ.

## Хичээлийн хувийн эх

Хичээлийн архив Git репогоос **гадуур Mac дээр** хадгалагдана. `content-studio/.local/config.json` файлыг зөвхөн Mac дээр үүсгэж `course_notes` түлхүүрт өөрийн эх JSON-ийн замыг заана. Эсвэл `ANANDA_COURSE_NOTES` орчны хувьсагч хэрэглэнэ. Эх нь `title`, `explanation`, `focus` зэрэг талбартай объектуудын жагсаалт байна.

```sh
.venv/bin/python scripts/prepare_topic.py --topic 'талархал' --out .local/brief-gratitude-v1.json
```

Энэ нь эхийн нэр дэвшүүлэлт. Контекстийг уншиж байж санааг баталгаажуулна. Таарах эх байхгүй бол тэр хязгаарыг хэлнэ. Хувийн эх, хайлтын үр дүн, суралцагчдын мэдээллийг GitHub, Claude болон өөр гадаад үйлчилгээнд дамжуулахгүй. Өмнө татгалзсан хувийн агуулгын дамжуулалтыг өөр аргаар давтахгүй.

## Skill

Репогийн `.agents/skills/zaya-ananda-content/SKILL.md` нь Codex-ийн төслийн skill. Claude хувилбар нь `content-studio/integrations/claude/zaya-ananda-content/SKILL.md` дотор; суулгагч зөвхөн шинэ skill хавтас үүсгэнэ. Хувийн тэмдэглэл skill-ийн багцад орохгүй. Claude-ийн хэрэглээ зөвхөн нийтэд нээлттэй/цэвэрлэсэн ерөнхий материалын хүрээнд байна. Skill суусан нь Claude акаунтаар нэвтэрсэн гэсэн үг биш.

Жишээ хүсэлт: **“Талархал сэдвээр төвийн хичээлтэй уялдуулж өнөөдрийн постер, постын тайлбар бэлд.”**

14 өдрийн сэдвийн санал `themes-14-days.json`-д байна. Өдөр бүрийн эхийн холбоог тусад нь шалгана. Нийтлэх цаг, платформын зөвшөөрөл тусдаа.

## Шалгах

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Тест нь фонтын монгол үсэг, PNG хэмжээ, хэтэрсэн эхийг зогсоох, хувилбарыг дарж бичихгүй байх, холбоогүй сэдэвт эх зохиохгүй байхыг шалгана. Харагдах байдал, монгол найруулга болон хэрэглэгчийн таашаалыг тест батлахгүй; PNG-г бодитоор хянана.
