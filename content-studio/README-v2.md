# Өдөр тутмын постер — шинэ загвар v2

2026-11-04-ний хэрэглэгчийн “дизайнуудыг арай сайжруулах” хүсэлтийн дагуу гаргасан шинэ санал. Хэрэглэгчийн харагдах байдлын үнэлгээг хүлээж байна. v1 болон өмнөх бүх жишээг хадгалсан.

## Өөрчлөлт

- Бүтэн нэртэй албан логог дээд зүүн хэсэгт, бичвэрийн баганатай зэрэгцүүлэв.
- Гол санаа зурагнаас өмнө уншигдана. Гарчиг Lora 82 px, хоёр мөрийн зайг бодит үсгийн хүрээгээр шалгана.
- Гарчгийн хоёр дахь мөрийг оюу өнгөөр ялгав. Энэ нь өнгөний шинэ санал; батлагдсан брэндбүүк гэж үзэхгүй.
- Зураг доод хэсгийг бүтэн эзэлнэ. Богино тайлбар гарчгийн дор, зурагнаас тусдаа байна.
- Нэг загвараар “Байгаль”, “Талархал” хоёр сэдвийг гаргасан. Урт өгүүлбэр багтахгүй бол үсгийг жижигрүүлэхгүй, найруулгыг товчилно.

## Үүсгэх

```sh
cd content-studio
.venv/bin/python scripts/render_post_v2.py --draft examples/nature.json --image examples/pine.png --out outputs/nature-v2
```

Шинэ эх: `brand/template-v2.json` ба `scripts/render_post_v2.py`.
Гаргалт: PNG, засварлах SVG, outlined SVG, постын тайлбар, 360 × 450 утасны хэмжээний жишээ, хэмжилтийн бүртгэл. SVG-г засах бол `brand/` доторх Lora болон Manrope фонт хэрэгтэй.

Хувийн хичээлийн эхийг хайх, контекстээр нь нягтлах болон нийтлэх зөвшөөрлийн дүрэм v1-ийн README-д бичсэнээр хэвээр үйлчилнэ. Энэ нь Facebook-д нийтлэх үйлдэл биш.
